# Z-Anatomy muscle model

This asset was copied unchanged from the user's existing project:
`Paper/trigger-point/src/assets/Z-Anatomy_Muscles_Interactive_Zones.glb`.
It was exported with Khronos glTF Blender I/O v5.1.20 (glTF 2.0).
The supplied file includes the project's interactive Zone_* grouping.

The original Z-Anatomy_Muscles_Interactive_Zones.glb is retained unchanged.
MuscleAtlas_Surface.glb, MuscleAtlas_Anatomy.glb and models/blender/muscle-atlas.blend
are derivatives created in Blender by scripts/anatomy/build-muscle-atlas.py.
Changes include a separate smooth skin envelope, illustrative coloured muscle
surface patches, smooth shading, flattened hierarchy, bilingual metadata and
exploded-view controls. Anatomical muscle vertex positions are retained;
the skin envelope is a simplified visualisation, not replacement anatomy.

The derived models, generated structure catalogue and bilingual structure
data retain CC BY-SA 4.0 attribution. Original English identifiers and Zone_*
membership are retained; Traditional Chinese names are display annotations.
