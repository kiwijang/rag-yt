# 💪 Muscle Atlas 3D

**你练的每一块肌肉，都值得被看见。**

一个为健身爱好者打造的交互式 3D 人体肌肉骨骼图鉴。不用再对着平面图猜"这块肌肉到底在哪"——旋转、点击、搜索，492 个解剖结构尽在掌握。

> *"深蹲到底练的是哪几块？" "肩袖肌群是什么？" "引体向上为什么背阔肌发力？"*
>
> 打开它，3 秒找到答案。

## 🎬 功能一览

- 🖱️ **360° 自由查看** — 旋转、缩放、平移，任何角度无死角
- 🔍 **中英文搜索** — 输入"背阔肌"或"latissimus"，自动飞到目标，其他部位变透明
- 💡 **点击即学** — 点击任意部位显示信息卡：功能描述 + 对应训练动作
- 👁️ **显示切换** — 骨骼 / 肌肉 / 全部，透明度自由调节
- 📐 **区域过滤** — 头颈 / 躯干 / 上肢 / 下肢，专注你关心的部分
- 🔲 **线框模式** — 看清深层结构
- 📴 **完全离线** — 无需联网，开个本地服务器就能用

## 📊 覆盖范围

**238 块骨骼 + 254 块肌肉 = 492 个解剖结构**

### 健身常用肌群 ✅ 全覆盖

| 部位 | 肌肉 |
|------|------|
| 🫁 胸 | 胸大肌（锁骨部 / 胸肋部）、胸小肌 |
| 🔙 背 | 背阔肌、斜方肌（上/中/下束）、菱形肌、竖脊肌 |
| 🦾 肩 | 三角肌（前/中/后束）、肩袖四肌（冈上 / 冈下 / 小圆 / 肩胛下肌）、大圆肌 |
| 💪 臂 | 肱二头肌（长/短头）、肱三头肌（长/外/内侧头）、肱肌、肱桡肌 |
| 🧱 核心 | 腹直肌、腹外斜肌、腹内斜肌、腹横肌、腰方肌 |
| 🍑 臀 | 臀大肌、臀中肌、臀小肌 |
| 🦵 腿 | 股四头肌（4 头全）、腘绳肌（3 块全）、内收肌群、缝匠肌 |
| 🦶 小腿 | 腓肠肌（内/外侧头）、比目鱼肌、胫骨前肌 |

## 🚀 开始使用

```bash
# 克隆仓库
git clone https://github.com/zhangguanghao523/muscle-atlas-3d.git
cd muscle-atlas-3d

# 启动本地服务器
python3 -m http.server 8765

# 浏览器打开
open http://localhost:8765
```
